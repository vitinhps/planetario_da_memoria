# Planetário da Memória
Planetário da Memória é um jogo desenvolvido para proporcionar diversão e desafios de lógica para crianças e adolescentes. O objetivo do jogo é formar pares de cartas, podendo escolher dentre os níveis "Fácil" e "Desafiador", cada um com suas peculiaridades. Descubra jogando! 
# Funcionalidades
- Sistema quantitativo de jogadas
- Mensagen de vitória
- Dois modos de jogo
- Embaralhamento de cartas
# Tecnologias e Linguagens utilizadas
- JavaScript
- React
- React Native Components
- Expo
